# 🚀 Menu de Exercícios - João Victor

Este é um portal responsivo e moderno desenvolvido para centralizar meus exercícios de lógica de programação e cálculos trabalhistas/financeiros.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica.
* **Tailwind CSS**: Estilização via classes utilitárias (moderno e dark mode).
* **JavaScript**: Manipulação de DOM para o relógio em tempo real.
* **Heroicons**: Ícones em SVG para interface.

---

## 📂 Estrutura de Projetos

O menu oferece acesso rápido aos seguintes módulos:

1.  **Cálculo de Horas Extras**: Sistema para processamento de jornadas adicionais.
2.  **Cálculo de Aumento de Salário**: Algoritmo para reajustes salariais.
3.  **Cálculo de Transporte**: Lógica para gestão de deslocamento de colaboradores.

---

## ⚙️ Funcionalidades em Destaque

### 🕒 Relógio em Tempo Real
O projeto conta com um script que captura a data e hora do sistema e a exibe formatada no padrão brasileiro (`pt-BR`), atualizando-se a cada segundo.

### 🎨 Interface UI/UX
* **Cards Interativos**: Efeito de *hover* que muda a cor do botão e desloca o ícone lateralmente.
* **Design Responsivo**: Adaptável para qualquer tamanho de tela.
* **Identidade Visual**: Tema escuro (*Slate 900*) com tipografia limpa.

---

## 🚀 Como Visualizar

1.  Clone este repositório: https://github.com/JvictorMarcon/Portif-lioJS.git
2.  Certifique-se de que as pastas `Exercicio 1`, `Exercicio 2` e `Exercicio 3` estão no mesmo diretório do `index.html`.
3.  Abra o arquivo `index.html` no seu navegador de preferência.
